You are on the right origin. This page and the teaching API come off the same local server, so the snippet can ask for /api/users/1 and the browser treats it as its own. No CORS, no local network permission prompt.

  1. Open DevTools, go to Sources > Snippets.
  2. New snippet, name it fetch-2026.
  3. Paste the const API = "/api"; line from fetch-2026.js, then build it up block by block. Cmd+Enter runs the whole snippet, Cmd+K clears.

The API, if you want to poke it by hand. Served by worker.js, the same file that runs on Cloudflare when this is published.
